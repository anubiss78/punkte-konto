# Punkte Konto

Android-App (Capacitor) für die Übersicht über Punkte und Meilen.

- `web/` ist die App-Oberfläche. Sie wird über GitHub Pages veröffentlicht, und die App lädt sie bei jedem Start. Änderungen hier kommen ohne Neuinstallation an.
- `web/data/offers.json` und `web/data/cards.json` enthalten Angebote und Kreditkarten. Sie werden wöchentlich aktualisiert.
- Die APK steht unter Releases → „Punkte Konto App“ → `PunkteKonto.apk`.
- Punktestände liegen nur auf dem Handy (localStorage), nicht in diesem Repository.
